# FeatherLite 2.3 (Fabric, Minecraft 1.21.11)
Feather-style client: custom main menu, Mod Menu (cards, tabs, search, accent colors), HUD editor,
per-module settings (size, color ring + custom hex color, background, opacity).
Modules: Keystrokes, CPS, FPS, Coordinates, Ping, Direction, Speed, Clock, Armor Status, Hitboxes,
Freelook (hold Left Alt), Zoom (hold C), Toggle Sprint. Freelook and Zoom keys can be changed from the gear button in the Mod Menu.
Open the Mod Menu in game with Right Shift (or from the main menu). Config: .minecraft/config/featherlite.json
